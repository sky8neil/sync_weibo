# 双发小助手（Chrome 扩展）v0.4

一键把消息发到**饭否**、自建 **Akkoma** 和 **Twitter/X**：支持图片（自动压缩 webp）、#标签、实时字数、发送通知与错误日志。

## 功能

- **实时字数统计**：超饭否 140 字、X 权重 280（中文约 140 字）提示；Akkoma 5000 字预警
- **图片（Akkoma + X）**：点「添加图片」自动压缩为 **webp、每张 ≤2MB**；**Akkoma ≤16 张 / X ≤4 张**（超过 4 张时 X 自动只发前 4 张并提示）；饭否不支持图片
- **#标签**：标签框输入（空格分隔）→ 发送时**追加给 Akkoma 与 X**（`#标签` 结尾、自动去重）；点「##」按钮可把标签直接插进正文（所有平台可见）
- **发送状态条**：发送中 / 发送成功 / 失败原因，一眼可见
- **系统通知**：发送完成（含失败）弹系统通知 —— **即使弹窗已关闭**（发送在后台完成）
- **错误日志**：最近 20 条发送记录保存在插件内部，打开弹窗随时查看（含报错详情）
- 五个按钮：发饭否 / 发 Akkoma / 发 Twitter / **Akkoma + X** / 同时发（3 平台）

## 安装

1. Chrome 地址栏打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`/home/fanfou-sender/extension`）
4. 工具条上出现「双发小助手」图标（可点拼图按钮固定）

> 从旧版升级：在 `chrome://extensions/` 点本扩展卡片上的「刷新 ⟳」即可。
> **兼容性**：已在**最新版 Chrome（154，Chrome for Testing 官方版）**实测通过（加载、发图、通知、日志全流程），也在 Chromium 120 上回归通过。

## 使用

点工具条图标 → 写消息 → 选按钮发送：

| 按钮 | 动作 |
| --- | --- |
| 发饭否 | 只发饭否（超 140 字自动截断并在结果中提示；不支持图片） |
| 发 Akkoma | 只发 Akkoma（可带 ≤16 张图与 #标签，正文上限 5000 字） |
| 发 Twitter | 只发 X（可带 ≤4 张图与 #标签，按权重 280 限字） |
| Akkoma + X | 同时发这两个（带图推荐用法；饭否不打扰） |
| 同时发（3 平台） | 三个平台各发一份（图片进 Akkoma/X，饭否仅文字） |

结果显示在状态条与日志区；发送完会有系统通知。

## 权限说明

- `storage`：保存配置与发送日志
- `notifications`：发送完成/出错时弹系统通知

## 常见问题

- **没看到系统通知？** 系统需允许 Chrome 弹通知（macOS：系统设置→通知→Chrome；Windows：通知设置；Linux：需 dunst/mako 类通知服务）
- **饭否为什么不能带图？** 饭否通道不支持图片；请选「发 Akkoma / 发 Twitter / Akkoma + X / 同时发」
- **最多几张图？** Akkoma：16 张/次；X：4 张/次（更多时自动只发前 4 张到 X，其余仅进 Akkoma）
- **X 对图片的要求？** 官方支持 jpg/png/gif/webp、单张 ≤5MB；本插件统一压缩为 webp ≤2MB（远低于上限，实测可发）
- **X 字数怎么算？** 按权重：中文/全角/emoji 算 2、西文算 1；280 权重 ≈ 140 个汉字；标签计入
